- Перевірений локальний Gitleaks: 8.24.3; checksum офіційного релізу перевірено.

- `bun audit --audit-level=high` пройшов у повторному CI запуску MarshGO на цьому SHA; окремі залежності все одно мають стандартний lifecycle-ризик і повинні перевірятися при кожному релізі.

## Не підтверджені або зовнішні ризики

- Живі SMS/OTP, платіжний acquiring, партнерські таксі/міжміські квиткові API та реальне бронювання не можна вважати підтвердженими лише через код адаптера. Доступ/партнерство позначаються `BLOCKED_EXTERNAL`, якщо немає успішного staging smoke з відповідними credentials.
- Немає підтвердження production deployment, production backup/restore або фізичного iPhone acceptance.
- Історична оцінка браузерних E2E `5 pass / 7 fail` надана як вхідна інформація. Вона не є результатом цього локального запуску; актуальний PR rerun ще завершується.
