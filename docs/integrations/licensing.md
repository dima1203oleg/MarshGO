# Open Data & Intellectual Property Licensing Compliance

## 1. Map Data & Cartography
- **OpenStreetMap (OSM)**: Open Database License (ODbL). Attributed on all rendered map views via MapLibre GL attribution control: `© OpenStreetMap contributors`.
- **OpenFreeMap**: Free vector tile hosting derived from OSM Planet dumps.

## 2. Municipal Open Data Licenses
- **Kyiv City Open Data**: Data provided via `data.kyivcity.gov.ua` under Ukrainian Open Data regulations. Commercial reuse permitted with mandatory attribution. Attribution displayed: `Дані: data.kyivcity.gov.ua`.
- **Lviv City Open Data**: Data provided by Lvivavtodor and Lviv City Council via `opendata.city-adm.lviv.ua`. Attributed as: `Дані: Львівська міська рада / Львівавтодор`.
- **Dozor & EasyWay Open Feeds**: Published under Ukrainian Law "On Access to Public Information". Attributed according to catalog references in `server/mobility/ukraineCatalog.ts`.

## 3. Commercial Software & API Licenses
- **Open-Source Dependencies**: No AGPL-licensed dependencies are packaged directly into client bundles.
- **Protobuf & GTFS**: MobilityData `gtfs-realtime-bindings` under Apache 2.0.
- **MapLibre GL JS**: BSD 3-Clause.
