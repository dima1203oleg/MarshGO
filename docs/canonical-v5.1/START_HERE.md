# MARSHGO 5.1 — START HERE (Codex)

Це єдиний стартовий пункт канонічного ТЗ для **основного MARSHGO**, не MARSHGO 2.

**Послідовність:**
1. Прочитати повністю [MARSHGO_CANONICAL_TZ_v5_1.md](./MARSHGO_CANONICAL_TZ_v5_1.md) — 601 рядок системного продуктового й технічного ТЗ.
2. Прочитати [CODEX_START_PROMPT.md](./CODEX_START_PROMPT.md) — чітке виконання й порядок.
3. Прочитати [DESIGN_REFERENCE_MAP.md](./DESIGN_REFERENCE_MAP.md) — п'ять погоджених фотоеталонів.
4. Перевірити всі чотири GitHub-репозиторії та актуальні гілки: [MarshGO](https://github.com/dima1203oleg/MarshGO), [MarshGO-Site](https://github.com/dima1203oleg/MarshGO-Site), [MarshGO-Server](https://github.com/dima1203oleg/MarshGO-Server), [MarshGO-iOS](https://github.com/dima1203oleg/MarshGO-iOS).
5. Якщо фото доступні в поточному завданні Codex — проаналізувати їх як референси. Якщо недоступні, не видавати їх за завантажені: виконати специфікацію з тексту та явно відзначити обмеження.
6. Перший результат: audit → матриця прогалин → технічна архітектура → план залежностей P0–P5 → невеликий перевірений PR (коли середовище дозволяє).

**Головні інваріанти:**
- Єдина карта, маршрут і дані між Search, Journey, навігацією, попутками, бронюванням, квитками та повідомленнями.
- Pure Drive: при активному русі карта, маршрут, маневр, GPS-швидкість, перевірене обмеження, ETA залишаються чіткими. Вторинні кнопки затихають.
- Під час активної навігації глобального центрального плюса немає; завершення — у розгорнутій нижній губі.
- «Схема / Супутник» — окремий квадратний перемикач; шари тільки тематичні, 3D незалежне.
- Жодних симульованих live-позицій, тарифів, місць, які видаються за реальні.
- Зміни робити через окремі гілки/PR, не торкатись production/main без перевірок і дозволу.

**Примітка:** файли знаходяться у відокремленій GitHub-гілці `docs/marshgo-canonical-v5-1`, а не в `main`. Тут немає ZIP і оригінальних бінарних фото — MD документи вже доступні через GitHub та не потребують ручного завантаження.
