# MARSHGO 5.1 — карта візуальних референсів

**Важливо:** п'ять оригінальних скриншотів користувача були надані в розмові ChatGPT і, за повідомленням власника, окремо в Codex. На цій GitHub-гілці **розміщені документи, але НЕ бінарні файли фотографій**. Codex мусить використовувати прикріплені до його завдання зображення, якщо вони доступні. Якщо недоступні — не вигадувати перегляд; вимоги з текстового ТЗ лишаються обов'язковими.

1. **REF_01_navigation_light.png** — світлий навігаційний дизайн: повноекранна карта, перегляд маршруту, активна навігація, шари.
2. **REF_02_journey_detail_expanded.jpeg** — темна розгорнута картка мультимодального маршруту: кольорова шкала, покроковий таймлайн, зупинки, окрема тривалість і вартість кожного сегмента.
3. **REF_03_journey_detail_compact.jpeg** — темна компактна мультимодальна картка: карта зверху, загальний ETA і ціна, стислий перелік сегментів.
4. **REF_04_journey_map_overview.jpeg** — повноекранна карта Львова з послідовною кольоровою лінією різних транспортних сегментів та позначками переходів.
5. **REF_05_search_results.jpeg** — список оптимальних, найшвидших, найдешевших варіантів із компактними сегментами, гривнями й хвилинами.

**Правила інтерпретації:** текст канонічного ТЗ вищий за картинку, суми з демонстраційних скринів — не фактичні; в Україні гривні; живі координати/транспорт — лише від перевіреного джерела; у режимі активної навігації немає центрального глобального «+»; Pure Drive ховає другорядний UI.
